2026 年 9 月 9 日，上海外滩大会的 AI 黑客松环节，一个熟悉又陌生的身影站上台，开场白是：「我是张蓝心。跆拳道全国冠军，演员，现在我靠写代码吃饭。」随后两天，#演员张蓝心用AI做奇门遁甲网站# 之类的词条挂上热搜，媒体报道的口径高度一致：影视「降本增效」（她的原话更狠——「不是寒冬，是液氮罐，连抖腿取暖的权限都没给我开通」）倒逼转型，她「手搓」了三款 AI 产品，其中一款死磕 30 多天上线、日活破千，而且「已经赚了钱」。

励志叙事网上已经够多了，这篇笔记干点别的：把这三款产品**到底是怎么做的、用了什么技术**尽可能还原出来。我的信息源分三层——她本人的一手内容（抖音合集《女明星与AI爱恨情仇》全 21 集、微博 @蓝心ZoeZhang、抖音评论区里她本人的回复）、媒体二手报道（用于交叉核对演讲内容）、以及我自己对产品公开入口的实测（HTTP 探测、证书与 DNS 解析，调研时间 2026-09-12）。所有推断性的内容都会明确标注。

先说结论：

1. **能实锤的技术栈只有一小截**：奇门遁甲网站出自「OpenClaw 智能体 + MiniMax 包月」的组合，她自己视频简介里的 #minimax #github #openclaw 三个标签和「目前花费：98 包月／没有续费」对得上号——98 元正是 MiniMax Coding Plan 当时 Plus-极速版的价格。「想得美」是标准的 BYO API Key（用户自带密钥）Web 应用，此外的宣传话术（「9 个 AI」「殿堂级导演分镜」）均无技术细节披露。
2. **两款已上线产品一个都访问不到了**：奇门遁甲从未公开过网址；「想得美」挂在抖音简介里的入口是个裸 IP（http://39.106.98.69），今天打开已经是另一家公司的官网——这个 IP 被云厂商回收复用了。我把她的全部公开渠道、证书透明度日志和爬虫档案逐一排查过：**没有任何迁移痕迹、没有新地址、没有下线声明**，而她的置顶视频至今还挂着这条死链。
3. **最有含金量的反倒是她的一条微博**：「AI 智能体 + 弱指令遵循模型 + 零验证 = 幻觉交付！！！口头闭环不算闭环，curl 输出才是真相。」这句话的工程成熟度，比整个热搜事件里任何一篇报道都高。

## 二、第一款：奇门遁甲——OpenClaw + MiniMax 包月跑出来的赛博起卦

三款产品里，第一款的信息反而是最完整的，因为她自己把账本晒了出来。

**技术栈实锤**。第 4 集视频简介的话题标签是 #ai #大模型 #minimax #github #openclaw，正文写着「我从『代码小白』到『奇门程序员』，把老祖宗的术数全塞进代码里！vibe coding 和 OpenClaw 终于通关！……目前花费：98 包月／没有续费」。这三件事互相咬合：

- **OpenClaw**：2026 年初爆火的开源个人 AI 智能体（前身 Clawdbot），logo 是一只龙虾，所以中文圈把部署、调教它的过程叫「养龙虾」。它能 7×24 小时挂着跑长程任务，通过浏览器、终端、各类 API 连接自主干活。3 月的中国 AI 圈几乎人手一只虾，连深圳坪山都出台了面向 OpenClaw 类智能体研发企业的最高百万元资助。
- **MiniMax 98 元包月**：MiniMax 官方的 Coding Plan（后升级为 Token Plan）按月订阅，生成专用 sk-cp 密钥即可接入 OpenClaw / Claude Code / Cline 等工具。2026 年 3 月那会儿的档位表里，Plus-极速版正好是 98 元/月（普通 Plus 是 49 元，Max 119 元）。她在 3 月 13 日微博里说的「98 元包月几天了用的没问题」、3 月 16 日说的「目前花费：98 包月 没有续费」，指的就是它。
- **GitHub**：OpenClaw 本体与配套生态都活在 GitHub 上，她视频里出现的工作流也符合「OpenClaw 驱动 + vibe coding 验收」的形态。

也就是说，这个网站的完整成本结构大概是：**一个月 98 元的模型订阅 + 一台跑 agent 的机器 + 她自己的时间和奇门遁甲领域知识**。她在微博里管它叫「我现在所有项目里最赚钱的项目（毕竟我财运确实好）」，而网站本身对外免费——免费的站怎么个赚钱法，她没披露过，评论区也看不到付费入口的痕迹，这里存疑。

**产品与运营侧写**。外滩大会上她的说法是「用最前沿的技术做最玄学的生意」，并提到曾有用户在网站上停留了 40 分钟。第 4 集评论区至今有真实的起卦互动：有用户说「姐姐，我想算出个吉，都是凶」，她本人回复「别同一时间 起卦」（这是正经的奇门规矩：一时一卦，不重复起）；还有人问「所以大坝的生门在哪里」，她回了一串省略号。这些互动说明网站当时确实对外可达——但**它的网址在任何公开渠道都找不到了**，视频简介和微博都没留，大概率当年就是评论区或私信里流转的私域入口。这也是它和「想得美」最大的区别：后者把地址直接写进了视频简介，于是有了后面第 4 节的故事。

**AI 总结功能的一手观察**：抖音给第 4 集自动生成的章节要点把她对奇门遁甲的理解概括为「古代数学、天文历法、逻辑推演和经验统计学的集大成」——她对术数的定位是「数术」而非「玄学」，这也解释了为什么它适合被规则化、代码化。

## 三、第二款：「想得美」——挂在裸 IP 上的 AI 导演平台

这是三款产品里唯一给出公开入口的，也是本次调研我下力气最重的一款。

### 3.1 产品定位：只管「画」不管「导」

她的差异化叙事在第 13 集里讲得很清楚：市面上的视频生成工具「只管画、不管导」——分镜带节奏、色彩有情绪、运镜有呼吸、构图有态度，这些是导演的工作，AI 不懂。「想得美」的解法是**先生成「殿堂级导演分镜头脚本与风格」，再按脚本生成视频**，即把她在片场摸爬滚打多年的「导演能力」蒸馏成中间表示层。外滩大会上媒体把这套说法概括为「导演蒸馏」。

从工程视角看，这是一个典型的「编排层」产品：

```text
用户输入（一句话创意）
   ↓  LLM 结构化输出
导演级分镜脚本（镜头、运镜、色彩、构图、节奏）
   ↓  逐镜头调用
视频生成模型 API
   ↓  拼接 / 排队 / 内容安全
成片
```

上游用的哪家视频模型，她从未官方披露过。已知的态度数据点是合集第 5 集——她实测吹爆过字节的 Seedance 2.0（「2K 电影级渲染管线……角色身份一致性优质」）。开源圈里同构的项目可以参照 [sjtuplayer/showvi](https://github.com/sjtuplayer/showvi)（Seedance2 agent 一键成片：输入一句话创意/小说/参考视频，多个专职 Agent 接力完成剧本、分镜、参考图直到成片），说明「分镜编排层 + 视频模型 API」这条管线在 2026 年已经是可复刻的成熟模式——**「想得美」的技术护城河不在架构，而在她注入的导演领域知识**，这一点她自己大概也是清楚的，所以反复强调「导演思维」而非「技术」。

### 3.2 产品形态：一个很诚实的 MVP

从第 13、14 集视频简介和评论区互动，能拼出相当完整的产品细节，每一条都有出处：

- **Web 平台，明确要求「用电脑打开」**——没有做移动端适配，MVP 味道很正。
- **BYO API Key**：「目前只需要您调用自己的 API」——用户自带密钥，她的服务器不承担模型调用成本。这是个人开发者做 AI 产品最聪明的成本转嫁设计。
- **首次免费**：第 14 集说「第一次免费直接点击生成视频」——没 key 的用户也能体验一轮，再引导配置。
- **异步等待**：「视频生成需要时间，请您耐心等待」——任务队列 + 轮询/刷新的架构。
- **内容安全**：「提示词不要太过于极端，会被 Biu 掉」——要么接了上游模型平台的内容审核，要么自己在 prompt 层做了拦截。
- **有管理后台**：评论区有用户说生成不了，她本人回复「我帮你后台查了一下，你的 key 写错了！你写了三遍！我一会出一个使用教程」——说明后端有请求日志能定位到具体用户的 key 状态。
- **数据**：外滩大会口径，日活跃用户突破千人，「三款产品已有稳定的日常收入」。

### 3.3 实测：那个裸 IP 现在是别人公司的官网

「想得美」的公开入口 http://39.106.98.69 是一个不带域名的阿里云北京段 IP。2026-09-12 我对它做了一轮探测，过程和结论如下（命令均可复现）：

```bash
$ curl -sI http://39.106.98.69/
HTTP/1.1 301 Moved Permanently
Server: nginx/1.26.3
Location: https://39.106.98.69/

$ curl -sk https://39.106.98.69/ | grep -o '<title>.*</title>'
<title>北京先锋寰宇招标有限公司</title>   # 证书警告忽略后拿到的内容

# 证书：
subject=CN=www.sun95.cn
issuer=DigiCert Inc, Encryption Everywhere DV TLS CA - G2
SAN: www.sun95.cn, sun95.cn

# DNS：
$ nslookup www.sun95.cn
Address: 39.106.98.69        # 域名与 IP 互相印证
```

也就是说：**「想得美」下线了，这台服务器（或这个 IP）如今属于北京先锋寰宇招标有限公司，跑着人家的官网**。三条证据互相咬合——HTTPS 证书是给 sun95.cn 签的（DigiCert 的 Encryption Everywhere 是云厂商随售的免费 DV 证书）、响应体是对方公司官网、www.sun95.cn 的 A 记录恰好解析回 39.106.98.69。

![访问 http://39.106.98.69 的现状（2026-09-12 截图）：证书警告之后，看到的是北京先锋寰宇招标有限公司的官网](/assets/images/2026/20260912/sun95-on-xiangdemei-ip.webp)

需要说明的是「IP 被回收」和「服务器被转卖」是两种可能，但无论哪种，结论对用户都一样：入口死了。

### 3.4 排查清单：有没有新地址？——截至 2026-09-12，没有

「平台是搬家了还是死了」这个问题，我把能查的渠道全部过了一遍，逐项记录如下：

| 排查渠道 | 结果 |
| --- | --- |
| 她的抖音主页简介与置顶视频 | 仍挂死链 http://39.106.98.69，无新地址 |
| 第 13/14 集视频评论区 | 9 月 11-12 日仍有用户在问「网址多少？」「哪里有继续访问？」（后者指的是证书警告页上的「继续访问（不安全）」按钮），两条均零回复 |
| 微博全部帖子的链接（t.cn 短链逐一展开验证） | 只指向她自己的微博视频，无平台链接 |
| 全网搜索（新地址/域名/关停声明等多种关键词组合） | 无任何结果，无迁移公告 |

| 她本人的公开口径 | 无任何下线/迁移说明；9 月 11 日回复网友「按你的经历生成个大女主剧」的请求时，只说「享受过程……结果不是我想要 …想要…就能要的」 |

证据链收敛成一句：**「想得美」从头到尾没有过域名，唯一入口随 IP 回收而永久失效，截至本文写作没有任何迁移痕迹、没有新地址、没有交代**。至于服务器是被攻击后主动下线、欠费释放还是到期不续，只有她自己知道——但对用户而言三者没有区别：一个日活千人的平台，无声无息地消失了。

### 3.5 一条被忽视的前史：它被攻击过

第 13 集评论区里有段很有价值的一手对话（2026 年 5 月前后）：

> 网友（白马非马）：姐姐 ip 放出来了，容易被攻击
> 张蓝心（作者回复）：**已经被攻击了……**

另一位网友（林帝）也问过：「姐，你的 ai api 都公开了你不怕跑光吗」。结合起来看：一个无域名、无 CDN、无 WAF 的裸 IP 站点，在抖音百万粉的流量曝光下，被扫描和攻击几乎是必然事件。站点后来是什么时候彻底下线的没有公开信息，但「被攻击」是本人亲口承认的。

## 四、第三款：还没揭盖的 SaaS

第三款产品在抖音第 12 集（4 月 22 日《自研SaaS平台 连续失败到底有多崩溃》）和微博（「一个人开发SaaS平台，无限翻车循环，全流程自研SaaS项目，从搭建到部署全程踩坑」）里只露过开发过程的「惨」，从未披露名称、形态和入口。外滩大会上的官方口径是：「等上线那天，我会第一时间告诉大家。但我可以透露一句：这个产品，是把前两次试错交的『学费』，变成了一张可以直接跑通的路线图。」

从 4 月开工到 9 月还没发布，这个节奏对独立开发者来说非常真实——前两款的「30 天」是幸存者叙事，第三款才是长跑。

**顺带一个媒体失真的活标本**：凤凰网某自媒体号的那篇《40岁女演员无戏可拍，靠写代码维持生活》流传很广，但它把 OpenClaw 写成了她的「第三个产品」——OpenClaw 是别人写的开源项目，是她的**工具**；同一篇文章还说她「目前还没有网站，只有抖音橱窗」，而事实上「想得美」当时有公开的 Web 入口。一篇通篇带对话细节和心理描写的「深度稿」，两处硬事实都是错的，转载链上没人纠正。看这类稿件时，能自己 curl 一把是多么幸福。

## 五、她的工程方法论：比热搜更有价值的部分

撇开产品，她两条 2026 年 5 月前后的内容值得单独摘出来，因为它们证明这不是玩票：

**5 月 3 日微博**：「AI智能体 + 弱指令遵循模型 + 零验证 = 幻觉交付！！！口头闭环不算闭环，curl 输出才是真相。当前 AI 智能体从『聊天玩具』迈向『生产力工具』，它们的智能，仍高度依赖于使用者的工程化约束能力。So～『不信任！只验证！物理证据闭环』，是当前阶段与所有 AI 智能体高效协作（的方式）。」

这段话放在任何一份 Agent 工程实践分享里都不违和——「验证闭环」正是智能体落地的核心难题。一个自述「数码小白」的人，在踩了一个月坑后能总结出这个认知，含金量比「日活破千」高。

**评论区的一位律师网友**（第 13 集）：「开始戴眼镜没太注意……后面你撸代码，我惊呆了，我懂代码，能看出来这是真在撸。」同一评论区还有人向她推荐 Codex 和 Claude Code，她回复「好哒！谢谢推荐」——她用的编程工具链（那「9 个 AI」具体是哪九个）从未公布清单，全部公开内容里能锚定的只有奇门遁甲线的 OpenClaw + MiniMax，以及她对 Seedance 2.0 的评测热情。网传的各种「工具清单」均为自媒体脑补。

## 六、工程复盘：做对了什么，翻车在哪

**做对的三件事**：

1. **BYO API Key 的成本结构**。模型调用费是 AI 产品最大的变动成本，让用户自带 key，平台只做编排，个人开发者的现金流压力直接归零。「纯技术展示、免费用」和「已经赚钱」能同时成立，架构选型功不可没。
2. **领域知识的产品化**。她没有去拼「更好的视频模型」（拼不过），而是把自己独有的导演经验做成模型上游的「分镜脚本层」。朱啸虎那句「所有 AI 应用都是套壳应用，关键是壁垒」在这里有个具体注脚：壳可以一样，注进壳里的领域知识不一样。
3. **公开建造（build in public）**。21 集合集把翻车全过程拍出来，「架构改了无数版，调试熬了无数夜」，既积累了关注，也倒逼自己持续交付。

**翻车的三件事**：

1. **裸 IP 部署**。这是整个案例里最刺眼的工程决策：不买域名（一年几十块），直接把云服务器 IP 印进视频简介。后果链完整呈现了——被扫描被攻击（本人承认）→ 站点下线 → IP 被回收复用成别家公司官网 → 置顶视频永久死链 → 用户问「哪里有继续访问」无人应答。域名是产品的第一份保险：IP 是租的，域名才是你的。
2. **运维与安全是 vibe coding 的盲区**。「30 天跑通」跑通的是功能闭环，跑不通的是 HTTPS 证书、WAF、DDoS、备份、监控这些「不产生故事」的环节。AI 能帮你写出应用代码，但帮不了你决定「要不要上 CDN」——那需要踩过坑才知道疼。
3. **传播链上的技术细节全部蒸发**。热搜文案里的「手搓三款 AI 产品」到读者端只剩励志故事；裸 IP、被攻击、站点已死这些事实，没有一篇热帖提到。反倒是 linux.do 上一条高赞跟帖的视角更接近行业真相（讨论胡彦斌手搓彦火 App 的帖子里有人提到她）：「抖音还有个艺人张蓝心，也在自己用 AI 做网站，作为一个大龄失业程序员，焦虑感又增加了。」——技术圈看到的是「AI 把开发门槛降到了艺人可上手」，娱乐圈看到的是「艺人都在转型了」，两种焦虑都是真的。

她自己倒是清醒，第 15 集标题就是「谁赢了？我怎么感觉卖课的老师们赢麻了～」——热搜的最大受益者从来不是建造者。

## 七、结语

张蓝心的故事被概括成「跆拳道冠军 → 动作演员 → AI 开发者」的三连跳，但把 21 集视频按时间铺开看，它更像一份「AI 时代个人建造」的完整标本：98 元起步的模型订阅、开源智能体、六个月试错、一款免费玄学站、一款日活千人的 BYO key 平台、一款还在长跑的 SaaS——以及一次教科书级的裸 IP 翻车。

「甭管哪个赛道，先上场再说」是她说给转型者听的；而工程世界补的那半句应该由这个案例来说：「先上场」之后，域名、证书、安全、运维这些旧世界的老规矩，一条都不会因为你是用 AI 写的代码就豁免。IP 会被回收，教训属于所有人。
