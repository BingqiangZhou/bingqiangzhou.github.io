## 一、理念课：自然拼读能做什么、不能做什么（Lesson 1）

先把三观摆正，这节课决定了你后面怎么用这套规律：

1. **自然拼读的作用**：帮助记忆词汇 + 提高阅读能力。**不能**用来猜发音，不可丢掉字典；
2. **覆盖率**：据文献参考，只有约 50% 的单词完全符合自然拼读规律（phonics 自己的发音 /ˈfɑːnɪks/ 就不怎么「规律」，更别提 colonel、aisle）；
3. **前提**：这个词本身你就认识——拼读是帮你建立「已会的音」和「拼写」之间的映射，不是破译生词的密码；
4. **影响因素**：词源（英语词源分日耳曼、拉丁两大支，本来就不「自然」）与特殊性；
5. **课程内容**：发音规律 + 可能的例外 + 约 300 个 sight words（高频视觉词，不服从规律，见一个记一个）；
6. **学习步骤**：学好音标 → 掌握拼读规律 → 记忆字母组合 → 放到例句中朗读。

贯穿全册的口诀：**先学发音，再学拼写规律**；遇到生词，先查字典，再用自然拼读去解释。

## 二、四个地基概念（Lesson 2–3）

### 2.1 元音字母与辅音字母

- 元音字母：**a e i o u**（五个）；辅音字母：其余 21 个；
- **y 是特别的一个**：音节开头是辅音/近音（yes、year、yet），音节中尾当元音——词尾 /aɪ/（by、try、dry）或 /i/（happy、funny、city）。

### 2.2 长元音与短元音

「长/短」不是指发音时长（音标篇已澄清），而是**是否读字母本音**：

| 元音字母 | 长元音（本音）| 短元音 |
| --- | --- | --- |
| a | /eɪ/ hate、lake、cake | /æ/ apple、map、mad |
| e | /iː/ be、me、he、she | /e/ met、egg、bed |
| i | /aɪ/ like、hi、bike、kite | /ɪ/ big、hit、sit、it |
| o | /oʊ/ no、home、note、phone | /ɑː/ not、dog、hot、off（美音）|
| u | /juː/ huge、mute、cute | /ʌ/ but、bus、hug / /ʊ/ pull、full |

任何元音在**弱读音节**都可能央化为 /ə/（about、banana、believe、police、support）。

### 2.3 开音节与闭音节（核心中的核心）

- **绝对开音节**：辅音 + 元音，元音后无辅音——me、hi、he、she、be、no → 长元音；
- **闭音节**：辅音 + 元音 + 辅音，元音被「关住」——not、hit、met → 短元音；
- **相对开音节**：辅音 + 元音 + 辅音 + **不发音的 e**（magic e / silent e）——note、mate、bike。末尾的 e 让音节重新变回开音节。

跟读对比组：hi/hit、go/got、me/met、be/bet、mate/mat、cane/can、rate/rat、bite/bit、wine/win、note/not、cope/cop、huge/hug、use/us。

四个细节：

1. magic e 和元音之间**至少隔一个辅音**，大多数情况恰好一个，偶尔两个（waste、change 仍是开音节）；
2. 前面的辅音可有可无，甚至两个（ate、hate、late、grade、grape、skate 都是开音节）；
3. **y 当 i 看待**，同样有三种音节：by/try（绝对开音节）、type（相对开音节）、happy（闭音节读 /i/）；
4. 探讨开闭音节时**不考虑 r**——r 音节单独一课；少数 r 音节词也符合开音节规律（fire、hire），sight words 不服从（come、love）。

## 三、26 个字母的声音印象（Lesson 4–10）

辅音字母与音素高度一一对应（详细发音机制见音标篇），自然拼读关注的是**字母在词中哪个位置发什么音**：

| 字母 | 读音 | 位置规律 | 例词 |
| --- | --- | --- | --- |
| b | /b/ | 词首词尾均可，词尾失去爆破 | bear、banana；lab、club |
| c | /k/ 或 /s/ | 默认 /k/；后接 e/i/y 时读 /s/ | cat、cup；city、cycle（详见软硬 c）|
| d | /d/ | 词尾失去爆破 | dog、desk；hand、cold |
| f | /f/ | 全位置稳定 | fish、farm；life、beef |
| g | /ɡ/ 或 /dʒ/ | 默认 /ɡ/；后接 e/i/y 常读 /dʒ/ | goat、girl；giant、gym |
| h | /h/ | 词尾常不发音 | house、hot；ah |
| j | /dʒ/ | 几乎只在词首 | juice、jam、just |
| k | /k/ | 词尾失去爆破 | key、kind；make、peak |
| l | light L / dark L | 词首 light L；词尾 dark L | lion、light；all、tell |
| m | /m/ | 全位置 | money、moon；same、film |
| n | /n/ | 词尾轻鼻音即可 | net、nice；in、can、plan |
| p | /p/ | 词尾可失去爆破 | peach、play；map、rope |
| q | /k/（+u=/kw/）| 几乎只在词首，后必跟 u | queen、quick、quiet、quit |
| r | /r/ | 词尾承担日化元音 | rabbit、red；car、her |
| s | /s/（语流或 /z/）| 全位置 | see、sun；bus、class |
| t | /t/ | 词尾失去爆破 | tiger、team；note、street |
| v | /v/ | 全位置 | value、vacation；five、love |
| w | /w/ | 几乎只在词首 | water、week |
| x | /ks/ 或 /ɡz/ | 多在词尾 /ks/；词中两读 | box、six；exam、exact |
| y | /j/ 或元音 | 开头辅音，中尾元音 | yes、yet；party、by |
| z | /z/ | 两端均可 | zoo、zero；amaze、buzz |

方法比清单更重要：**替换性练习**——同一个音配不同辅音和元音大量组合（b: bear→bird→bed→black→lab→club），把字母 - 声音映射练成肌肉记忆。

## 四、五个元音的词族替换练习（Lesson 11–15）

闭音节短音的训练方式是 **word families**——固定词尾换首辅音，一组一组刷：

| 词族 | 例词 |
| --- | --- |
| a: ap / at / am / an / ax / ag / ad | cap map nap tap；cat fat bat rat hat mat；am ram jam yam；an fan man pan can；tax max fax wax；bag tag rag lag；dad mad had bad sad |
| e: en / ed | pen ten hen men went lent tent cent；bed fed wed red led |
| i: ip / ib / id / in / ig / it / ix | hip lip zip dip ship slip skip；bib rib；kid lid mid；in pin bin fin win；fig wig big dig pig；it hit sit fit bit；six fix mix |
| o: og / ot / op / ox | dog log fog bog；not hot lot got pot dot；hop top mop pop；fox ox box |
| u: ug / up / un / um / ut | bug rug hug mug tug；up cup mud bud；sun fun run nun gun；mum gum hum yum；nut hut but cut |

要点提示：

- a 的 /æ/ 多出现在**重读闭音节**；
- e 是英语书面语中使用频率最高的字母；弱读时大部分用 schwa /ə/ 顶替；
- i 的短音在语言学里叫松元音；非重读音节里 /ɪ/ 常弱化成 /ə/（believe、family）；
- o 美音读 /ɑː/；
- u 的 /ʌ/ 本身就接近 /ə/（音标篇 Lesson 4 的结论在拼读里同样成立）。

## 五、r 音节：Bossy R（Lesson 16–17）

**定义**：音节中的元音后紧跟 r 时，元音被 r「控制」，不再遵循闭音节读音，整体构成新音节。美式发日化元音，英式只发紧元音不日化。

| 组合 | 美音 | 例词 |
| --- | --- | --- |
| ar | /ɑːr/ | car、bar、far、large |
| er / ir / ur | /ɜːr/ | teacher、term；bird、firm；hurt、burn（英式 /ɜː/）|
| or | /ɔːr/ | for、form、sort、lord、corner |
| are | /er/ | care、bare、glare、stare、dare |
| ere | /ɪr/ | here、mere、sphere、sincere（例外：where /wer/）|
| ire | /aɪər/ | hire、fire、tire、admire |
| ore | /ɔːr/ | more、bore、store、core |
| ure | /ʊr/ | sure、cure、pure |

两个补充：er 是「执行者」后缀，大量职业/工具词以 er 结尾（cooker、dryer、teacher、dancer、singer）；**单词里没有 r 就不日化**——音标篇的铁律在拼读里依然成立。

## 六、schwa 与拼读（Lesson 18）

音标篇讲过 schwa 的发音，拼读视角的补充是它的**分布规律**：

- 非重读音节的元音大概率读 /ə/：schwa a（about、alive）、schwa e（record）、schwa i（family、ability）、schwa o（police、protect、computer）、schwa u（support、supply）；
- /ɪ/ 弱读成 schwa（famous、breakfast）——互为音位变体。

这条规律反过来用就是**重音定位法**：一个多音节词里那个发得最清楚、最饱满的元音，就是重音所在。

## 七、规则精华：三条件卡片（Lesson 19–26）

讲义后八课是「最有价值的规律」密集区。每条规则都用「条件 + 例词 + 例外」的卡片式整理：

### 7.1 软硬 c 和软硬 g（Lesson 19）

- **条件**：c/g 后接 **e、i、y** → 软音 /s/、/dʒ/；
- **否则**（其他元音或辅音）→ 硬音 /k/、/ɡ/；
- 软 c：face、center、city、cinema、circus、cycle、icy、lucy；软 g：orange、gentle、giant、giraffe、gym、biology；
- 硬 c：cat、cold、cut、cry、club；硬 g：gas、game、go、gun、green、glad；
- **例外**：get、girl、gift、give（g + i 仍是硬音）——学一个记一个。

### 7.2 FZSL 规则（Lesson 20）

- **条件**：① 单音节词；② 音节里是短元音；③ 以 f/s/z/l 结尾 → 结尾字母**双写**；
- 例词：staff、grass、pass、class（/æ/）；less、mess、tell、smell（/e/）；cliff、miss、kiss、ill、still、kill（/ɪ/）；tall、ball、small、call（/ɑː/）；stuff、puff、fuzz、buzz、full、pull（/ʌ/）。

### 7.3 ck 与 -k 的分布（Lesson 21）

- **条件**：① 单音节词；② 短元音后 → 结尾写 **ck**；非短元音（长元音、字母组合）后 → 写 **k**；
- ck：pack、black、neck、deck、trick、sick、mock、lock、luck、duck、stuck；
- k：cake、make、like、hike、poke、spoke（长元音 + k + e）；peak、leak、task、desk、think、pink（组合或辅音后 + k）；
- 一句话：**短元音 -ck，不是短元音 -k**。

### 7.4 tch 与 dge（Lesson 22）

- **条件**：① 单音节词；② 中间是短元音；③ 词尾 /tʃ/ 写 **tch**、/dʒ/ 写 **dge**；
- tch：catch、match、fetch、itch、stitch、pitch、clutch；dge：badge、hedge、bridge、dodge、judge；
- 原理：**d 保护了元音不被 magic e 规则改读**（badge 若写成 bage，a 就要读 /eɪ/ 了）；
- **例外**：such、much、rich、which——tch 规则的反例，直接记。

### 7.5 去 e 加 ing 及元音后缀（Lesson 23）

- **条件**：词尾是 silent e，后缀以**元音开头** → 先去掉 e 再加后缀；
- making、taking、baking、liking、hiking、riding、writing、joking、muting、assuming；
- 同理适用于 -er（dancer、receiver）、-able（makable、lovable）、-ous（famous、nervous）、-ed（hated）；
- 细节：give → giving、love → loving、dodge → dodging——即使违反开音节直觉，元音后缀一律去 e。

### 7.6 重读闭音节双写（Lesson 24）

- **条件**：① 加元音开头的后缀；② 后缀前是**重读**闭音节；③ 词尾辅音字母只有一个 → **双写辅音**再加后缀；
- planning、banning、getting、letting、hitting、digging、nodding、hugging、putting；
- -ed：stopped、dropped、flipped、preferred；-er：runner、winner（以及比较级 bigger、hotter、fatter、thinner）；-y：funny、sunny、doggy、foggy；
- 判定要点是「重读」：forget → forgetting、begin → beginning、prefer → preferring，但 prohibit → prohibiting（重音不在）；dining/dinning、siting/sitting 的最小对比正是这条规则的试金石。

### 7.7 名词复数（Lesson 25）

| 结尾 | 变化 | 例词 |
| --- | --- | --- |
| 一般情况 | + s | cats、dogs、maps、books、birds |
| s / x / z / ch / sh 结尾 | + es | buses、classes、foxes、boxes、brushes、dishes、watches、quizzes |
| o 结尾 | 多数 + es，部分 + s | potatoes / pianos |
| f 结尾 | 部分变 ves | leaf → leaves；例外 roof → roofs |

例外学一个记一个，不硬找规律。

### 7.8 y 的变形规则（Lesson 26）

- **元音 + y**：直接加后缀——play/played/playing、toy/toys、enjoy/enjoyed；
- **辅音 + y**：y 变 i 再加后缀——family → families、party → parties、carry → carried、happy → happiest、lucky → luckiest；
- **i 开头的后缀**（-ing/-ish）：y 保留不变——flying、cried 与 crying 并存、babyish、greyish。

讲义在最后一课的总结值得原文引用：自然拼读剩下的规则 ①不适用于很多单词；②看一个学一个。自然拼读是「脑力活动和体力活动的分水岭」——规律给你地图，剩下的靠替换练习的体力。

## 八、本篇速查卡

- 一个核心映射：**开音节 → 长元音（字母本音），闭音节 → 短元音**；magic e 是音节开关；
- 辅音看位置，元音看音节类型，一切例外先查字典再解释；
- 三条件规则族（FZSL / ck / tch / dge）共享「单音节 + 短元音」前提，背条件比背单词划算；
- 拼写变形四连：**去 e**（元音后缀）、**双写**（重读闭音节）、**变 y 为 i**（辅音后 + 非 i 后缀）、**+s/+es**（擦音结尾）。
