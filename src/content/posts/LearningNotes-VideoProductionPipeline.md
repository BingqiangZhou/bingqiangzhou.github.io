> 写作动机：我之前拆过一批 AI 视频工具（video-agent-kit、erduo-broll-loop-engineering、video-shotcraft 等），拆得越多越发现缺一块底座——这些工具到底在自动化视频制作的哪一段？这篇就把「视频制作的一般流程」这个教科书问题完整梳理一遍，作为后续所有拆解笔记的方法论地图。下一篇[《AI 资讯日报如何视频化》](/posts/ai-news-daily-video-production/)就是拿这张地图做的第一个应用。

## 一、太长不看：一张地图

先给结论。所有视频制作流程的**最大公约数**是四段骨架：

```text
前期（策划 / 脚本 / 分镜）
   → 中期（拍摄 / 素材采集）
   → 后期（剪辑 / 声音 / 画面 / 包装）
   → 分发（发布 / 数据复盘）
```

不同形态只是对这个骨架做加减法。从最重到最轻：

| 形态 | 阶段划分 | 团队规模 | 流程重心 |
|---|---|---|---|
| 电影 / 剧集工业 | 5 阶段（开发→前期→拍摄→后期→发行） | 数十至数百人 | 开发融资 + 部门化协作 |
| 商业广告 / 宣传片 | 三段式 + 客户确认节点 | 5–30 人 | 创意提案与客户审片 |
| 知识区 / 口播自媒体 | 四段压缩版 | 1–3 人 | 脚本与剪辑节奏 |
| 抖音竖屏短视频 | 四段极简版 | 1 人 | 分镜表与黄金 3 秒 |
| AI 原生流程（2026） | 脚本→生成→终剪 | 1 人 + 工具链 | 提示词与素材一致性 |

英文世界的标准表述来自影视教育体系：[Lone Star College](https://www.lonestar.edu/33315.htm)、[Central Casting](https://www.centralcasting.com/spotlight/blog/the-three-stages-of-tv-and-film-production) 和 [StudioBinder](https://www.studiobinder.com/blog/stages-of-film-production) 都以「Pre-Production / Production / Post-Production」三阶段为核；[Charter Films](https://charter.film/blog/video-production-process-the-5-key-stages-explained) 在两端加上 Development（开发）和 Distribution（发行），构成五阶段——这是目前最完整的工业口径。中文世界（[稿定设计的流程详解](https://m.gaoding.com)、[百度百科「后期制作」](https://baike.baidu.com)）普遍用「前期筹备 / 中期拍摄 / 后期制作」三段式，口径一致。

下面从最重的形态讲到最轻的，最后提炼六条在所有形态里都成立的规律。

## 二、电影 / 剧集工业流程：最完整的形态

电影工业之所以值得先看，不是因为普通创作者用得上，而是因为**它把每个环节都展开到了部门 granularity，是流程的「全息底片」**——其他形态都是它的裁剪。

### 2.1 开发（Development）：从创意到「能开机的项目」

写剧本（多稿修订）、做「包装（package）」——把剧本、主创（导演、主演）、预算合在一起，向投资方或片厂推销，融资立项。这一步可能持续数月到数年，是项目生死的第一道闸门。开发期产出的三样东西——定稿剧本、预算表、周期表——是后续所有阶段的法律与执行依据。

### 2.2 前期（Pre-production）：把「能拍」变成「怎么拍」

StudioBinder 的定义很准确：**融资完成到开机之间的一切准备工作**。具体包括：

- **预算与排期**：总预算分解到部门，拍摄周期表（production schedule）按场景统筹拍摄顺序（顺场拍摄，不按剧情顺序）；
- **组建部门**：制片组、导演组、摄影组、灯光组、录音组、美术 / 服化道，各司其职；
- **选角（casting）与堪景（location scout）**：定了演员和场地，预算才能锁死；之后还有**技术堪景（tech scout）**——各部门到现场实地定机位、灯位、电源方案和收音方案；
- **视觉预演**：分镜（storyboard）、previz（3D 预演）、shot list（镜头清单），把「怎么拍」提前画出来。

### 2.3 拍摄（Production / Principal Photography）

现场创作由导演把控，流程由第一副导演（1st AD）把控，每天凭**通告单（call sheet）**开工——几点集合、拍哪些场景、需要哪些演员和设备，全写在一张单子上。现场有一套标准化的拍摄口令协议（roll camera → mark → action → cut），把几十个人的协作钉在同一秒上。

拍摄期的隐形关键部门是 **DIT（数字影像工程师）**：负责现场素材的备份与校验（多副本 + 校验和）、转码低码率**代理文件（proxy）**交给剪辑部门、整理每日样片（dailies）给主创审看。素材在这一步管理混乱，后期就是灾难——这条规律往下所有形态都成立。

### 2.4 后期（Post-production）：内部还有一条严格的流水线

[Adobe 的后期指南](https://www.adobe.com/creativecloud/video/post-production.html)提到电影后期可长达半年到一年。内部工序大致是一条这样的链：

1. **图片剪辑**：合版（assembly，把所有可用条按剧本顺序拼起来）→ 粗剪（rough cut）→ 精剪（fine cut）→ **画面锁定（picture lock）**。锁定之后画面不再改，其他部门（调色、声音、特效）才敢全力开工，否则改一帧、全线返工。
2. **套底（conform）**：剪辑师用低码率代理剪，定剪后调色环节把代理**换回原始高分辨率素材**，这个替换流程叫套底；调色完成后把各环节的工程文件再返回剪辑工程，叫**回批（roundtrip）**。这两个术语的通行定义来自知乎张家硕 2015 年的高票回答「中外电影工业里面电影剪辑的流程分别是什么」——他同时指出，Pr / FCPX / 达芬奇之间的往返协作正是靠这套机制打通的。知乎还有一套《视频后期制作流程之完全指南》八篇系列，其中[套底篇](https://zhuanlan.zhihu.com/p/98723397)把这一步定义为「将影片项目从剪辑师的语言转换给色彩和声音团队的流程，最微小的细节将决定这个阶段的成败」。
3. **调色**：一级校色（统一曝光与白平衡）+ 二级调色（分区风格化）。调色师罗立全在 ftrack 的访谈里把「DIT 素材管理 → 代理交接 → 剪辑 → 定稿 → 调色」的部门接力讲得很清楚。
4. **特效 / 合成（VFX）**：擦威亚、CG 场景、合成，工业光魔级别的活。
5. **声音制作**：对白编辑、ADR（补录对白）、拟音（Foley）、音效、作曲配乐、终混。北京电影学院导演系公开课的影视后期与声音创作讲座强调：长片中声音剪辑和混音是与画面剪辑并行且同等重要的工序——「画面一半，声音一半」。
6. **字幕与包装**：片头片尾、字幕、物料。

中文百科口径的传统五步是「初剪 → 正式剪辑 → 作曲选曲 → 特效录入 → 配音合成」（[百度百科·后期制作](https://baike.baidu.com/item/%E5%90%8E%E6%9C%9F%E5%88%B6%E4%BD%9C)），本质相同，只是工序归并方式不同。

### 2.5 发行（Distribution）

营销物料（预告片、海报、剧照）、送审定档、按影院 / 流媒体 / 电视 / 移动端的不同规格交付母版。知乎《完全指南》系列的交付篇（第 8 篇）把这一步描述为「所有媒体资源将被打包、优化并整合，提供给网络平台、广播电视、影院或移动设备」——注意，**交付本身是一道独立工序，有规格、有验收**，不是「导出完事」。

## 三、商业广告 / 宣传片：叠加客户确认节点

商业视频的骨架没变，变的是**决策权的分布**——客户介入后，每个阶段之间多了确认闸门：

```text
Brief（客户需求）
   → 创意提案（脚本 + 故事板一起提）
   → 报价与 PPM 会议（制作前会议，锁死所有细节）
   → 拍摄
   → 后期
   → 客户审片（通常约定修改轮次）
   → 多版本交付（不同时长 / 平台 / 语言）
```

台湾制作公司 ArtVision 的[商业广告制作流程](https://artvision.com.tw)和[稿定的流程详解](https://m.gaoding.com)都提到一个行业现实：不少公司采用企划→脚本→拍摄→剪辑→调光→动画的「一条龙」内部流程来降低沟通成本。这类流程的特点是**前期确认极重**——故事板定了才开机，客户签字才进后期，修改轮次写进合同。我调研时印象最深的一点是：广告流程里「返工」是最贵的，所以整个流程设计都在把决策尽量前移。

## 四、知识区 / 口播自媒体：单人流水线（B 站 / YouTube 型）

把工业流程的部门全部裁掉，一个人（或 1–3 人小团队）跑完同一条骨架：

1. **选题**：维护选题库，蹭热点或做常青内容；
2. **脚本**：钩子（前 3–5 秒留人）→ 主体内容 → 行动号召（CTA）的结构。知识区视频的脚本密度远高于即兴口播——大部分 UP 主是「稿子先行」，读稿或提词器，而不是想到哪说到哪；
3. **录制**：A-roll（口播画面，重点解决提词器、打光、收音三件事——[翔宇工作流的口播教程](https://xiangyugongzuoliu.com/talk-to-camera-without-freezing)还强调横竖屏要先按平台定：抖音 / 小红书竖屏，B 站 / YouTube 横屏）+ B-roll（录屏、素材画面、空镜）；
4. **剪辑**：粗剪搭结构 → 精剪删口误、卡节奏。B 站有[新手 0–1 保姆级教程](https://www.bilibili.com/opus/724936461949861893)覆盖设备→口播→打光→剪辑软件全链，适合入门对照；
5. **包装**：字幕、花字、BGM、转场、片头片尾；
6. **发布**：封面缩略图 + 标题 + 标签 + 发布时间。封面和标题对点击率的影响不亚于视频本身；
7. **复盘**：看完播率、点击率、留存曲线，反哺下一期选题。

注意这条流水线和电影工业的**同构性**：步骤 2 对应开发期的剧本，步骤 3 对应拍摄期的 A-roll/B-roll（就是两个「机位」），步骤 4 的粗剪 / 精剪对应合版 / 粗剪 / 精剪三稿，步骤 6–7 对应发行 + 数据回流。骨架没变，只是一个人干了十个部门的活。

## 五、抖音竖屏短视频：快节奏变体

流程骨架继续压缩，每一步都被强化到「以秒为单位」：

- **选题**：追热点、追情绪价值；
- **脚本**：三类（口播型 / 拍摄型 / 剧情型），[人人都是产品经理](https://www.woshipm.com/operate/4977300.html)把前期总结为「确定主题 → 情境预估（预判拍摄现场）→ 信息整理」三步；
- **分镜**：以镜头为行做**分镜表**，字段包括镜号、景别、运镜、画面内容、台词 / 字幕、音效、时长。[知乎那篇 4000 字分镜脚本长文](https://zhuanlan.zhihu.com/p/127208419)给了完整的案例模板——15 秒到 1 分钟的视频照样逐镜规划，因为竖屏信息流里「黄金前 3 秒」决定完播，节奏必须精确到秒；
- **拍摄 / 剪辑 / 发布**：一机一位一软件（剪映级）走完。

抖音流程给我最大的启发是：**视频越短，前期占比越高**。15 秒的片子，分镜表可能要做 10 行——「快」是设计出来的，不是拍出来的。

## 六、AI 原生流程（2026）：拍摄被生成替代

AI 改造的是骨架里的**中期环节——拍摄被生成替代**，其余环节保留但换了工具：

```text
脚本：LLM 生成 / 改写（钩子-主体-CTA 结构不变）
   → 分镜：AI 辅助拆分镜，难点是角色一致性
   → 素材：文生图 + 图生视频替代实拍
   → 声音：AI 配音 / 音色克隆替代真人录制
   → 剪辑 / 字幕：智能剪辑、自动字幕
   → 终剪：仍需人工把关节奏与连贯性
```

几个一手观察（来自我拆过的工具）：

- **分镜层的「配方化」**：我拆过的 [video-shotcraft](/posts/video-shotcraft-skill-deep-dive/) 把镜头动效做成 152 张可查询的镜头配方卡，本质是把「导演的视觉语言」变成 Agent 可检索的结构化知识——这对应传统流程里的分镜 / previz 环节；
- **口播层的「字级时间戳」**：[video-talkcraft](/posts/video-talkcraft-skill-deep-dive/) 把每个动效钉在人声字级时间戳上，解决的是「画面和人声对不齐」这个后期最琐碎的活——对应声画对位；
- **剪辑 Agent 的证据链**：[video-agent-kit](/posts/zcode-video-agent-kit/) 用抽帧 contact sheet 让模型「看」视频、用文件契约 + SHA-256 追溯链让剪辑决策可审计、用 Stop hook 拦住没闭环就收工——这是把 DIT 的素材纪律和后期的审片制度做成了机器可执行的规范；
- **B-roll 精工 vs 量产的矛盾**：[erduo-broll-loop-engineering](/posts/erduo-broll-loop-engineering/) 用剧组制多 agent 做逐镜精修，公开基准是约 3 分钟片端到端 4 小时量级——精工路线的成本决定了它不适合日更；
- **行业工具面**：2026 年的 AI 视频工作流已经出现「画布式流水线」（把分镜、角色、预演、生成、剪辑做成节点拖拽连线，[品玩的对比文](https://www.pingwest.com/a/317392)），[elser.ai 的入门指南](https://www.elser.ai/zh/blog/ai-video-creation-workflow-for-beginners-in-2026-from-zero-to-published-in-one-afternoon)甚至演示了一下午从零到发布。更系统的两条技术路线（生成式 vs 代码渲染）我在[《AI 视频生成全景》](/posts/ai-video-generation-survey/)和[《Video-as-Code 全景》](/posts/code-to-video-survey/)两篇里分别梳理过。

一个清醒的判断：目前全自动化管线的输出，**最后一公里普遍是人**。AI 吃掉的是机械环节（转写、对齐、粗剪、字幕），「这个片子讲什么、节奏在哪断、哪条信息值得放大」仍然是人的判断——而这恰恰是传统流程里前期和精剪干的事。所以 AI 不是改变了流程，是把流程的重心进一步压回了前期。

## 七、六条底层规律

把五种形态并排放着看，有六条规律反复出现：

1. **前期决定成本**。脚本、分镜、堪景每多花一小时，拍摄和后期就少返工十小时。电影把钱花在开发期，广告把闸门设在提案期，自媒体把杠杆放在脚本期，抖音把功夫下在分镜表——形态不同，逻辑相同。
2. **素材管理是隐形生命线**。从工业级的 DIT + 代理剪辑 + 套底回批，到个人创作者的文件夹命名规范，本质都是「让素材可追溯、让低配设备剪得动高码率素材」。出了问题最先怪罪的往往不是创意，是素材。
3. **声音与画面分离处理**。外行重画面、内行重声音——收音质量、对白清晰度、混音层次对观感的影响超过画质。电影给声音独立部门，口播 UP 主第一笔投资是领夹麦，两端都验证了这条。
4. **剪辑是「再写作」**。合版→粗剪→精剪→锁定的三稿节奏说明剪辑不是技术操作，而是第二次剧本创作；自媒体的「粗剪搭结构、精剪卡节奏」是同一件事的低配版。
5. **交付随平台分化**。横屏 16:9 / 竖屏 9:16、时长规格、封面标题体系——「发布」本身已是流程中不可省略的独立工序，且有数据回流闭环（完播率、点击率反过来决定下一期的选题）。
6. **形态之间是裁剪关系，不是替代关系**。懂了电影五阶段，往下裁掉部门化就是广告流程，裁掉客户节点就是自媒体流程，把拍摄换成生成就得到 AI 流程。反过来，个人创作者遇到瓶颈时，解法往往藏在「往上一级形态借一个环节」——比如日更崩溃时，该借的是工业流程的模板化和素材纪律，而不是更努力地熬夜。
