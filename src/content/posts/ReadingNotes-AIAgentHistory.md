学一门新技术，我习惯先看它的历史：为什么它长成今天这个形态，哪些设计是历史包袱，哪些是刻意为之。Datawhale 把《Hello-Agents》第 2 章「智能体发展史」以万字长文的形式发在公众号上，正好补上了这块拼图。这篇笔记把约 1.1 万字的原文压成一条主线和四段演进；文中提到的演进阶梯图、发展时间线和 Agent 技术栈全景图在公众号原文里，值得对照着看。

## 一条主线：问题驱动的范式迭代

原文最提纲挈领的观点是：智能体的每一次范式更替，都是为了解决上一代范式的核心痛点；而新方案在带来能力飞跃的同时，又会引入当时难以克服的新局限，为下一代范式的诞生埋下伏笔。理解了这个「问题驱动」的循环，再看今天 Agent 技术选型里的种种争论——要不要规划、要不要记忆、要不要多智能体——就能发现它们各自对应着历史上某一代范式缺失的能力。

## 符号主义：把智能编码成规则

符号主义（也称「逻辑 AI」）时代的信念是：人类的智能，尤其是逻辑推理能力，可以被形式化的符号体系捕捉和复现。理论根基是纽厄尔（Allen Newell）与西蒙（Herbert A. Simon）1976 年提出的**物理符号系统假说（PSSH）**，包含两个论断——充分性（任何物理符号系统都具备产生通用智能行为的充分手段）与必要性（任何展现通用智能的系统本质上必然是物理符号系统）。它把「机器能否智能」从哲学问题变成了可以工程化实现的问题。

这一范式最成功的产物是**专家系统**：知识库存放专家的 IF-THEN 产生式规则，推理机负责正向链（数据驱动，从事实推到结论）或反向链（目标驱动，从假设反推证据）推理。代表作 MYCIN（斯坦福，1970 年代）用约 600 条规则辅助诊断细菌性血液感染，还首创了置信因子（CF）来处理医学诊断的不确定性，评估中的表现超过了非专业医生。另一个里程碑是威诺格拉德（Terry Winograd）1968-1970 年的 **SHRDLU**：在「积木世界」里，它首次把语言解析、规划、记忆等模块集成进一个统一系统，能做指代消解、利用上下文、自主规划动作序列，甚至回答「你为什么拿起红色积木」——「感知 - 思考 - 行动」闭环的雏形在这里已经出现。

但符号主义有两大类根本性挑战，最终成为它的天花板：

- **知识获取瓶颈与常识问题**：专家知识要靠人工访谈提炼成规则，成本高、难规模化，且大量内隐知识根本无法显式表达；人类习以为常的常识（「水是湿的」）更是无法穷举编码——Cyc 项目数十年努力的成果依然有限。
- **框架问题与脆弱性**：动态世界里执行一个动作后，如何高效判断哪些事物没有变化是逻辑难题；而完全依赖预设规则的系统一旦遇到规则之外的情况就可能整体失灵。SHRDLU 的成功恰恰因为它活在一个人工封闭的世界里。

## ELIZA：规则方法的活标本

原文用一个编程实践把符号主义的局限演示得非常直观——复现 1966 年魏泽鲍姆（Joseph Weizenbaum）的聊天机器人 **ELIZA**。它的机制是纯粹的模式匹配四步：关键词识别与排序、通配符分解、代词转换（I→you、my→your）、重组模板生成回应，几十行 Python 就能跑起来。

ELIZA 最有意思的是那个悖论：魏泽鲍姆的设计初衷是证明「机器可以在完全不理解对话的情况下营造出智能与共情的假象」，结果大量用户（包括他的秘书）却对它产生了情感依赖——这就是著名的「ELIZA 效应」。而它的三大局限也正是符号主义困境的注脚：**无语义理解**（处理不了否定词）、**无状态**（每次回应只基于当前单句）、**规则爆炸**（规则库越大，冲突与优先级管理越不可维护）。看似智能的表现完全依赖预先编码的规则，面对真实语言的无穷变化注定不可扩展。

## 明斯基《心智社会》：智能从交互中涌现

单一、集中的推理引擎走不通，那智能还能怎么构建？明斯基（Marvin Minsky）在 1986 年的《心智社会》（The Society of Mind）里给出了革命性的回答："What magical trick makes us intelligent? The trick is that there is no trick."——智能的力量来自大量简单部分的多样性协作，而非任何单一完美的原则。

在这个理论里，「智能体」指极其简单的专门化心智过程（如识别线条的 LINE-FINDER、负责抓握的 GRASP），它们自身「无心」，被组织成完成更复杂任务的机构（Agency）。经典的搭积木塔例子：BUILD-TOWER 机构激活 BUILDER，BUILDER 只会循环激活 ADD-BLOCK，ADD-BLOCK 再依次激活 FIND-BLOCK、GET-BLOCK、PUT-ON-TOP……没有任何一个模块掌握全局规划，但通过简单的激活与抑制信号，搭塔这个看似高度智能的行为就**涌现**了出来。

这套思想为分布式人工智能与后来的**多智能体系统（MAS）**提供了概念基础，具体启发了三件事：去中心化控制（没有中央控制器如何协调分工）、涌现式计算（蚁群算法、粒子群优化这类从局部交互中产生解的方法）、智能体的社会性（智能体通信语言 ACL、契约网协议、协商与信任模型）。今天讨论 multi-agent 架构时，思想源头就在这里。

## 学习范式三部曲：感知、决策与知识

如果智能无法被完全设计出来，那能否被学习出来？原文用三个范式回答了「学什么」：

- **联结主义**：知识不以规则形式存储，而是分布式地存在神经元连接权重中，靠反向传播等算法从样本中调整权重。深度学习的成功让智能体获得了直接从原始数据（图像、声音、文本）理解世界的**感知能力**——这是符号主义时代难以想象的。
- **强化学习**：解决「感知之后如何决策」。智能体与环境在「状态 - 行动 - 奖励」的循环中试错，学习目标不是即时奖励而是累积回报（所以会有围棋里的「弃子」）；AlphaGo 的自我对弈是经典体现。但它需要海量针对特定任务的交互，缺乏先验知识。
- **大规模预训练**：解决「开始学习前先理解世界」。在互联网级语料上以「预测下一个词」为目标自监督预训练，再按下游任务微调；跨过规模阈值后涌现出上下文学习（ICL）与思维链（CoT）等未被直接训练的能力。LLM 由此同时成为海量知识库与通用推理引擎——符号主义时代最棘手的知识获取瓶颈，被以一种全新的方式解决。

## LLM 智能体：所有拼图的合流

最后的合流点就是今天的主角——以 LLM 为核心的现代智能体，其骨架是一个持续迭代的循环：

1. **感知**：感知模块从环境接收原始输入（用户指令、API 返回、状态变化），形成观察；
2. **思考**：规划模块通过反思与自我批判把宏观目标分解为可执行步骤，LLM 结合记忆模块整合历史信息，推理出下一步行动——通常表现为一次工具调用；
3. **行动**：执行模块解析指令，从工具箱中选择并调用工具（代码执行器、搜索引擎、API）作用于环境；
4. **循环**：工具结果与被改变的环境状态构成新一轮观察，LLM 同时更新记忆，进入下一轮感知 - 思考 - 行动。

用原文的话说，这是三大思潮的深度融合：符号主义提供了逻辑推理的框架，联结主义（Transformer）提供了 LLM 这个「大脑」本体，行为主义（强化学习）提供了从反馈中优化行为的方法——现代 Agent 本质上是一种神经 - 符号架构。原文末尾还提供了两张值得收藏的图：从 1950 年代至今的智能体发展演进时间线，以及 Letta 公司 2024-11 发布的 AI Agent 技术栈全景。

## 几点体会

- **现代 Agent 的每个核心组件都对应一段历史缺失**：记忆模块对应 ELIZA 的无状态，规划模块对应符号系统的手工编码知识，工具调用对应专家系统的封闭知识库。读史之后再看 Anthropic 方法论那句「从最简单的方案开始，按需增加复杂度」，会更理解每块拼图的代价。
