最近在 GitHub 上闲逛时刷到一个叫 [side_pro](https://github.com/geeeeeeeek/side_pro) 的仓库，163 star、192 commits，描述是「程序员副业项目总结，整理总结了一些适合程序员的副业赚钱方法，包括网站 adsense、网站集成亚马逊佣金、兼职接单等等」。作者是 YouTube 频道 [@java1024](https://youtube.com/@java1024) 的博主（自称程序员 Tim），这个仓库是他副业系列视频的图文配套。

我把里面 49 篇 Markdown、1 个 Python 脚本和 2 个 HTML 页面全部读完之后，觉得它值得写一篇完整的笔记——不是把内容搬运一遍，而是拆开看三个问题：它的方法论是否成立、数据是否可信、有哪些它自己不谈的风险。最后再跳出仓库本身，聊聊程序员副业这件事还能往哪里延伸。

先亮一个阅读立场：仓库里几乎所有 VPS、IP、广告联盟的链接都带 aff 返利参数，**这个仓库本身就是作者副业的一环**。看的时候要意识到，它的推荐排序里有利益因素，数据（尤其是收入数据）无法第三方验证。

## 一、仓库速览：一条完整的内容主线

先看结构。整个仓库只有三样东西：

- `README.md`——按主题分类的教程索引，混合图文链接和 YouTube 视频链接；
- `docs/`——49 篇 `.md` 正文 + 1 个 Python 脚本 + 2 个 HTML（其中一个是从仓库部署到 GitHub Pages 的 HostDare 优惠码页）+ 5 张评测配图；
- `.gitignore`。

没有一门真正的「代码」。按主题归类，内容分布大致是：

| 板块 | 篇数 | 内容 |
| --- | --- | --- |
| 变现复盘 | 约 7 篇 | 收入分享、五步方法论、RPM 优化、广告联盟对比、提现 |
| 建站教程 | 约 12 篇 | Cloudflare / Firebase / GitHub Pages / Netlify / 谷歌云五种托管路线 + 四个具体站例 |
| VPS 评测 | 约 14 篇 | 八家横评、单厂评测、库存监控、低价盘点 |
| 住宅 IP | 2 篇 | iProyal / NextIP 静态住宅 IP 评测 |
| 运维与 AI 工具 | 约 6 篇 | SSH / Vim / fail2ban / Claude Code / OpenClaw 接 DeepSeek |
| 独立项目 | 2 篇 | text2voice 在线工具（全仓库最有工程含量）、多因子股票打分脚本 |

所有内容串起来是一条主线，可以一句话概括：**找 GitHub 现成源码 → 白嫖免费托管（或低价 VPS）→ 绑一个老域名 → 挂广告联盟 → 海外收款**。

作者公开晒出的关键数字有三个，可信度自判：3 个网站 9 个月 AdSense 后台合计 \$1400+；一个在线修图单页站运行 3 年赚了 \$2000+；帮美国华人搭外贸独立站半天收 900 元。就算全部打折，也足以说明这条路「能跑通但赚不多」——作者自己的原话是「虽然钱少，但是稳定」。

## 二、核心方法论：五步 Adsense 流水线

仓库方法论上最干的一篇是《我如何通过 Adsense 副业网站半年赚 8000 元》，把过程拆成五步。我逐步转述，并加上我自己的批注。

### 第 1 步：找关键词（选题）

用 Google Trends、Bing Webmaster、Keyword Planner 三个工具组合找有搜索量、竞争度低的关键词。

批注：这一步本质是「需求探测」，决定整个项目 80% 的成败。仓库没有展开怎么组合使用这三个工具，细节都留在视频里——这也是全仓库的普遍问题：图文是视频的提纲，不是替代品。

### 第 2 步：GitHub 找源码（产品）

在 GitHub 搜目标工具（比如「图片编辑器」），优先选纯 HTML 或能打包成单页 HTML 的项目，下载后二次开发：改 SEO、优化加载速度。

批注：选「纯 HTML 项目」是个聪明的约束——部署零依赖、托管零成本、改起来零门槛。代价是所有人都能这么干，同一个开源项目被几百个人部署上线，同质化极其严重。这是这条路线最大的隐性成本，后面风险一节展开。

### 第 3 步：域名 + 服务器（资产）

域名在 Namesilo、Namecheap、阿里云等平台买，必须选主流后缀（com/net/org），太便宜太冷门的不要。服务器以稳定为主，IP 不能被封。另一篇谷歌云教程里给了两个很实在的经验值：**域名注册要超过 3 个月，谷歌收录最好超过 20 条**，否则 AdSense 很难过审。

批注：「域名是资产，服务器是耗材」是这个仓库少数真正值得记住的观念。老域名有注册龄和历史收录，冷启动快得多；而托管随便换。作者还踩过一个真实的坑：某站选了日本机房，国内访问绕美国一圈回来，速度慢一倍，广告收入每天只有几毛钱——线路质量直接乘进收入里。

### 第 4 步：接入 AdSense（变现）

谷歌 AdSense 后台新增网站、贴广告代码、等审核。过不了审就换 Adsterra（下一节展开）。

### 第 5 步：外链与 AI 写文（流量）

用 51la 监测流量；推广靠外链——多发文章、交换友链、争取导航站收录；并且明确建议**用 ChatGPT 批量写文章**。

批注：这是全仓库时效性最差的一条建议。2023 年前后靠 GPT 批量生成页面做 SEO 的窗口期确实存在，但谷歌随后多轮打击规模化低质内容（helpful content 导向的算法更新），大量 AI 内容站被降权甚至除名。今天照抄这一步，大概率是在给算法递刀子。

五步串起来，可以抽象成一个五层模型，后面所有内容都挂在某一层上：

```text
资产层   老域名（注册龄 > 3 个月、有收录历史）
产品层   GitHub 现成源码 + 二次开发（SEO 与加载速度）
托管层   免费层：CF Pages / Firebase / GitHub Pages / Netlify / 谷歌云
流量层   谷歌 SEO + 外链 + 内容（AI 辅助）
变现层   AdSense（过不了审降级到 Adsterra）→ Payoneer 提现
```

## 三、托管层：零成本矩阵怎么选

仓库用 Cloudflare、Firebase、GitHub Pages、Netlify、谷歌云免费层五条路线各写了一篇教程，其中 Firebase 那篇附了一张和 Cloudflare Pages 的对比表，是仓库里信息密度最高的表格之一。我把它和其余几条路线合并整理：

| 托管路线 | 免费额度 | 部署方式 | 特点与坑 |
| --- | --- | --- | --- |
| Cloudflare Pages | 流量不限、每月 500 次构建 | 连 GitHub 自动构建 | 小白友好；`pages.dev` 二级域名国内间歇被污染 |
| Firebase Hosting | 10GB 存储 / 10GB 月流量 | 本地 CLI `firebase deploy` | 超额不扣费只停服；自带数据库/认证/云函数，适合全栈站 |
| GitHub Pages | 公开仓库免费 | push 即部署 | 最简单；仓库本身还能吃谷歌权重 |
| Netlify | 免费档够小站用 | 网页拖拽文件夹 | 零门槛，适合演示 |
| 谷歌云免费层 | 一台常驻小机器 | 自己装 Nginx | 唯一能跑后端的「免费」路线，但要会 Linux |

两个仓库反复强调的结论值得单独摘出来：第一，`web.app` 和 `pages.dev` 这类免费二级域名在国内都会间歇被污染，**做 AdSense 必须绑独立域名**——托管可以白嫖，域名不能省；第二，如果网站需要用户登录、存数据，选 Firebase；纯静态工具站选 Cloudflare Pages。

对照我自己：这个博客跑在 GitHub Pages 上，域名年费几十块，和仓库结论完全一致。零成本矩阵这一层是仓库最不过时的部分，因为它描述的是平台的免费政策，变化相对慢。

## 四、变现层：广告联盟的段位与收款

《主要广告联盟评测对比》是全仓库最值得截图收藏的一篇，用游戏段位把主流联盟排了序：

| 段位 | 联盟 | 门槛 | 结算 | 一句话点评 |
| --- | --- | --- | --- | --- |
| 青铜 | Adsterra / Monetag | 零流量门槛 | Net-15，最低 \$5，支持 USDT | 1 分钟过审，给钱痛快，但广告杂 |
| 白银 | Google AdSense | 原创内容 + 人工审核 | Net-21，最低 \$100 | 单价高且稳定，但审核玄学、易封号 |
| 黄金 | Ezoic | Access Now 已零门槛 | Net-30，最低 \$20 | 自动广告位收益比 AdSense 高 30%-50%，代价是拖慢网页 |
| 黄金 | Journey by Mediavine | 1 万月会话 | Net-65 | Mediavine 预科班，要求欧美流量 |
| 王者 | Mediavine | 5 万月会话 | Net-65，最低 \$25 | RPM 行业天花板，审核极慢 |
| 王者 | Raptive | 10 万月浏览 | Net-45，最低 \$25 | 顶级站专属，普通站长不必想 |

这张表的实际用法是一个「升级路线」：新站先挂 Adsterra 保证有流水 → 内容和流量起来后过 AdSense 审 → 会话量过万再逐级申请 Ezoic、Mediavine。仓库里那个在线招聘站、屏幕检测站走的都是「AdSense 难过审、直接 Adsterra」的务实路线。

收款端结论同样务实：PayPal 和 Payoneer（P 卡）各备一个。PayPal 币种多但国内提现难；Payoneer 可以直绑国内银行卡（作者实测农行、招行都行）、注册即送一个美国银行账号、余额达标还能申请实体卡在国内 ATM 取现。做自由职业和跨境电商的，P 卡比 PayPal 顺手。

## 五、仓库里最有工程含量的一篇：text2voice

如果只允许推荐仓库里的一篇，我会选《从零搭建一个免费的文本转语音在线工具（Flask + Edge TTS）》。它是全仓库唯一一篇完整讲「怎么把一个想法做成可靠小服务」的文章，而不是「怎么把别人的代码挂上线」。

这篇文章的看点在于工程闭环的完整性：

- **选型对比**：把百度语音、讯飞、Web Speech API、Edge TTS 按音质、免费额度、下载支持三个维度列表对比，选微软 Edge TTS——免费无调用限制且音质接近真人；
- **降级设计**：后端 Edge TTS 挂掉时，前端自动切换浏览器内置的 Web Speech API，用户照样能听，只是失去下载能力——一个典型的优雅降级；
- **防滥用**：单次 1000 字 + 每 IP 每小时 10 次的限流，考虑到了免费服务被人薅秃的现实；
- **踩坑实录**：edge-tts 是 asyncio 而 Flask 是同步框架，用 `asyncio.run()` 包装；音频流要收集完所有 chunk 再返回；CORS 处理。

这套东西——选型表、降级方案、限流、部署（Nginx 反代 + nohup）——正是程序员相对非程序员的真差异化。第 2 节那套「五步流水线」里，非程序员唯一做不了的其实只有二次开发；而 text2voice 展示的是从 0 构建的能力，这个差距不是「会用 GitHub」能弥补的。

顺带一提，仓库唯一的代码文件 `gemini-python-stock.py`（多因子美股打分器，基本面 35% / 技术面 30% / 量价 20% / 新闻情绪 15% 加权）当作 Python 数据分析阅读材料不错，当投资建议不行——因子全是公开指标的简单加权，没有回测。

## 六、延伸思考一：这门生意的本质是信息差 + 返利飞轮

跳出教程本身，这个仓库最有意思的地方是：**它本身就是作者副业方法论的一次实践**。

拆开看作者的变现结构：GitHub 图文仓库（吃「程序员副业」这类关键词的谷歌 SEO）→ 导流 YouTube 频道（广告分成）→ 文内 aff 返利链接（VPS、住宅 IP、广告联盟的推荐码）→ 自有 AdSense 工具站矩阵。四层变现互相导流，GitHub 仓库是漏斗顶部的免费内容。

这解释了仓库的几个特征：为什么 192 commits 持续更新（内容半衰期短，平台政策、算法、价格都在变，停更就失权重）；为什么 VPS 评测占 14 篇（返利最直接）；为什么收入数字只晒后台截图（信任是漏斗的转化率）。

它也回答了「163 star 意味着什么」：「程序员副业」这个需求真实存在且足够大，大到「教别人做副业」本身先成了一门副业。这类信息差生意自古存在，互联网只是把漏斗成本降到了接近零。

## 七、延伸思考二：仓库不谈的风险清单

教程仓库天然报喜不报忧，补上它不谈的部分：

1. **内容合规**：仓库有一篇 Cloudflare + LibreTV 搭影视站的教程。LibreTV 本身只是播放器壳，内容源来自第三方采集接口，在多数司法辖区这属于版权高危区，商用（挂广告）更是加重情节。
2. **算法风险**：如第 2 节批注，ChatGPT 批量生成内容做 SEO 的窗口期已过，谷歌对规模化低质内容的打击是持续方向。靠 AI 灌内容的站，收益曲线是先涨后断崖。
3. **账号风险**：AdSense 对无效点击极敏感，作者自己在多个教程里反复提醒「不要自己点广告」「不要刷量」——反过来读，说明这是最常见也最致命的死法，封号几乎无法申诉。
4. **平台依赖**：免费托管政策说变就变（额度收紧、二级域名污染加重、免费层关停），五层模型里托管层看似零成本，实则是唯一不受自己控制的一层。多平台冗余是必须的。
5. **IP 用途边界**：住宅 IP 评测里讲的「养号」「防关联」场景，在部分平台的条款里本身违规，封号损失自担。

一句话：这条路线的下行风险不是「赚不到钱」（大不了白干），而是「账号资产清零」——AdSense 账号、域名、谷歌收录，任何一个被封都是慢资产的损失。

## 八、延伸思考三：程序员该抄什么、不该抄什么

**值得抄的：**

- text2voice 式的工程闭环（选型 → 降级 → 限流 → 部署），这是可积累、可迁移的能力；
- 零成本托管组合拳，以及「域名是资产、托管是耗材」的资产观；
- 「多个小站组合」而非单站押注的思路——3 个站合计 \$1400，单站可能只有几百，但组合的方差小；
- 广告联盟段位表，无论做不做 AdSense，理解变现生态的分层数据本身有价值。

**不值得抄的：**

- 纯工具站路线的同质化内卷：GitHub 上同一个开源项目被几百人部署、抢同一批关键词，红海程度可想而知，后来者几乎没有超额收益；
- 用低质广告换用户体验（Adsterra 的弹窗类广告对站点评级是净伤害）；
- 为返利写「评测」——短期赚钱，长期透的是自己的信用资产。

更本质地说：这条路线里程序员的优势被高估了。五步流水线里只有第 2 步（二次开发）用到编程，而且门槛不高；真正稀缺的是 text2voice 那种从需求到可靠服务的能力，以及第 1 步的选题眼光。**编程是这条流水线上最不稀缺的环节**——这是读完全仓库之后我最大的反直觉结论。

## 九、如果真的想试：一份冷启动清单

假设读完还想动手，把仓库内容压缩成一份两阶段清单：

**第一周（验证，预算 ≈ 一个域名钱）：**

1. 用 Google Trends + Keyword Planner 找 3 个搜索量稳定、竞争度低的关键词；
2. 每个关键词在 GitHub 找一个纯 HTML 开源工具，本地跑通；
3. 买一个主流后缀域名（com/net），注册后先把站挂上去让它开始积累域龄；
4. 托管选 Cloudflare Pages 或 GitHub Pages，绑域名，提交 Search Console 和 sitemap。

**第一个月（起量与变现）：**

5. 每个站补 5-10 篇「人写的」针对性内容（AI 可以辅助，别让它执笔全文）；
6. 收录过 20 条后申请 AdSense，被拒就先挂 Adsterra 保持流水；
7. 用 51la 或 GSC 盯流量，砍掉两周零流量的站，把时间投给有数据的站；
8. 注册 Payoneer，把收款链路先打通——很多人是赚到 \$100 之后才发现提不出款。

红线只有一条：不刷量、不点自己的广告。

## 十、结语

side_pro 的价值不在于教程本身——大部分教程是视频提纲，数据无法验证，返利立场明显。它的价值在于**完整展示了一条低成本、可复制、但天花板也低的路线**：五层流水线每一层都有免费方案，意味着入场成本趋近于零，也意味着护城河趋近于零。

对我而言，这次通读最大的收获有两个：一是「域名是资产」和「多站组合降低方差」这两个可以直接挪用的观念；二是看清了「教人做副业」本身就是一门信息差生意——所以看任何教程，先看作者的变现结构，再决定信几成。

以及，全仓库最好的一篇不是任何一篇「赚钱教程」，而是那个文本转语音小工具的构建记录。副业只是出口，把想法变成可靠小服务的能力才是存货。
