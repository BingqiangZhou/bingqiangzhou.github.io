前几天调研 [biji.com/openapi](https://www.biji.com/openapi) 的「把得到大脑带进常用聊天工具」是怎么实现的，把它的前端代码翻了个底朝天（飞书一键建智能体、企微扫码建机器人、钉钉自建应用 + Stream 长连接、微信小步扫码 + 六位安全码，细节见下文第六节）。顺手把整个产品盘了一遍，发现聊天工具只是冰山一角——这家公司（北京思维造物，就是罗振宇的得到）搭的是一套相当完整的"AI 记忆"系统。这篇笔记把调研到的东西全部摊开，按一手/二手信息分层记录。

先说结论：

> **得到大脑 = 记录层（万物皆可记）× AI 加工层（发芽/点评/拷问/润色 + 记忆库）× 输出层（知识库订阅 + 一键成文）× 硬件（AI 录音卡）× 开放生态（MCP/CLI/Skill/OpenAPI/聊天机器人）**。它真正想卖的不是笔记功能，而是"你的第二大脑"——所有入口都往同一个记忆库里灌数据，然后用订阅制把记忆的加工能力包月卖。第三方对它的评价很典型："小步 AI 背后的模型不算特别强大，但够用"——模型不是壁垒，**数据积累和得到十年内容库才是**。

产品背景一句话：原 Get 笔记（主打"语音说完自动变笔记"），2026 年升级更名得到大脑（官方 iOS 文档口径：v3.0.0 完成升级），公司是北京思维造物信息股份有限公司，即得到 App 的母体。

## 一、记录层：万物皆可记

得到大脑的记录入口多到夸张（以下均为官方使用文档的口径）：

| 记录方式 | 说明 |
| --- | --- |
| 语音速记 | 说话即记录，AI 自动转写 + 整理，"懒得打字？说出来就行" |
| 会议录音 | 多人会议，区分说话人，AI 出总结（章节概要、金句、待办） |
| 课堂录音 | 主打"上课录音，下课出学霸笔记"，重点标记、知识点梳理 |
| 手机内录 | 内录播客、B 站直播等 App 内声音，边听边记 |
| 链接一键记 | 粘贴公众号文章、抖音/小红书/B 站短视频、得到直播回放链接，AI 出精华总结 |
| 拍几张照 | 拍照/截图秒变笔记，识别图中内容 |
| 智能拍书 | 拍纸质书页面，"纸质书笔记永不丢失" |
| 导入音视频 | 导入本地音视频文件出转写和总结（免费 600 分钟/月） |
| 微信小程序 | 微信里长按内容"在小程序工具中打开"选得到大脑，随手记录 |
| AI 录音卡 | 硬件记录，见第四节 |

多端覆盖也齐：iOS、Android、鸿蒙、MacOS、Windows 客户端、浏览器插件、微信小程序、网页端；iOS 侧还做了桌面小组件、Siri 唤起和快捷指令（官方文档专门有教程）。另外支持从印象笔记、有道云、微信读书等多平台**导入已有笔记**，官网把它作为独立卖点（"轻松导入笔记，让知识汇聚"）——典型的"先把你的存量数据搬进来"策略。

免费版的额度（官网价格页 2026-09 口径）：语音记录 10 分钟/次，会议/课堂/手机内录各 1 小时/次，知识库 10 个共 30G，导入音视频 600 分钟/月，录音卡转写 600 分钟/月，四大 AI 能力各 5 次/月。

## 二、AI 加工层：四大专属能力 + 记忆库

### 2.1 发芽、点评、拷问、润色

这是得到大脑宣传的"独家 AI 能力"（官网原话：从记录中生长洞察），每个录音笔记都能被 AI 从四个角度"复盘"（官方文档 + 第三方评测口径）：

- **发芽**：不是存储也不是检索，而是理解记录的"思想内核"，跨领域、跨时空建立关联，从旧记录里"长出全新认知"。官方例子：记了曾国藩的"既往不恋，当下不杂，未来不迎"，发芽报告识别出内核是"活在当下"，关联出爱因斯坦"我从不去想未来，因为它来得已经够快了"和《功夫熊猫》乌龟大师的类似语录。触发后 3–5 分钟出报告，有推送通知；前提是必须有新的录音笔记。
- **点评**：自动发现记录里的亮点，"随时被看见"。
- **拷问**：指出内容的逻辑问题或立场风险，"诤友随身旁"。
- **润色**：优化文字表达，"出口就成章"，打磨成适合公开发布的内容。

免费用户每项每月 5 次，会员期内无限。

### 2.2 记忆库：第二大脑的本体

记忆库是官方定位的"记忆中枢"——"你说过的、听过的、写过的、看过的，它都记得"。四个来源自动汇聚，无需手动整理：**得到 App 的学习记录**（课程、书籍、笔记，需关联得到账号）、**录音卡录音**、**知识库资料**、**日常笔记**。

能力上，它不只是攒数据：能跨时间、跨场景连接记录，官方甚至宣称能发现"你今天说的和上周有点矛盾"这类前后关联。App 端记忆库分三块（官方文档）：

- **小步眼中的你**：动态更新的个人档案（会员/专家版专属）——AI 根据你的全部记录给你画像，还能**导出给其他 AI 用**，免去重复自我介绍；
- **记忆资产**：记忆总量及四来源分布；
- **时间线**：按时间排列、可筛选的记忆留痕。

### 2.3 小步 AI 与辅助功能

小步是跑在记忆库上的 AI 助手，App 内直接对话，"记忆越多越懂你"，四大专属能力也因此更个性化。得到大脑 App 和得到 App 账号关联后，小步的记忆库两边打通（官方 FAQ 口径）。回答可以限定内容源为得到课程/电子书/听书，**答案附引用超链接**——这是得到内容生态的直接变现点。

细节功能还有三个（官方文档）：**声纹识别**（会员功能，让 AI 认识你的声音、分清谁在说话）、**语音口令**（录音中喊口令就能划重点）、**语音词库**（自定义专有名词让转写更准）。

## 三、知识库订阅与成果输出

### 3.1 个人知识库：不只是放笔记

知识库（Topic）是"更高级的笔记整理与再创作方式"，除了导入笔记和上传文件（PDF/Word/PPT，单文件 ≤200M），最有意思的是**订阅能力**（官方文档）：

| 订阅类型 | 用法 | 效果 |
| --- | --- | --- |
| 得到直播、视频号直播 | 上传直播链接或预约截图 | 自动生成直播重点纪要（用"罗老师学习笔记"的专业模板） |
| 抖音博主 | 粘贴博主个人主页链接 | 自动追更该博主内容 |
| 视频号博主 | 上传博主主页截图（单个视频号短视频无对外链接，只能这样） | 自动获取该号更新 |

也就是说它把"信息源订阅 → 自动消化 → 入库"做成了产品能力，配合"每日下午 1 点自动更新"之类的定时任务（第三方教程口径）。知识库内可以做文件夹管理、分享，官方文档说团队协作"未来会加入"；还有开放平台的知识库 API（见第六节）。

### 3.2 成果输出：一键成文

"成果输出"让小步把记忆库素材直接变成作品（会员功能）：对小步说想法或选定记录，产出标注"文稿 · 作品 · V1"的成稿；同一作品可以反复生成 V2、V3（更口语、更克制等不同风格）；作品能转成长图/多图分享卡片，满意的作品再存回记忆库供日后调用。适用场景官方给了三个：一键成文（从当天记录挑适合发朋友圈的）、素材整合长文（一段时间的录音笔记合并成公众号文章）、多版本打磨。

## 四、硬件：得到 AI 录音卡（GetSeed）

得到的第一款 AI 硬件，跨年演讲上首发、首波一万份售罄（第三方报道口径），评测普遍归入 2026 年初上市的产品。一张信用卡大小（54×85.6×3.1mm，约 28.4g）的录音卡，型号 GSC10：

| 项目 | 参数（我爱音频网评测实测口径） |
| --- | --- |
| 续航 | 连续录音 35 小时，待机 60 天 |

| 连接 | 蓝牙 V6.1 + 2.4GHz Wi-Fi（支持 Wi-Fi 快传） |
| 识别 | 30 种外语、27 种方言 |
| 电池 | 400mAh |
| 收音 | 三麦克风（含骨传导），8 米远距离收音 + AI 降噪，揣兜里也清晰（官方/第三方口径） |

使用方式：长按 MARK 键约 1 秒开机，App 侧边栏绑定；录音不需要连 App，四种模式（语音速记/多人会议/手机内录/课堂录音）自动切换，**录音中来电会自动切成通话录音**。录音自动同步到得到大脑，转写区分说话人，AI 总结含章节概要、金句、待办，然后就能发芽/点评/拷问/润色。

价格与会员绑定（第三方渠道口径，电商促销价常有浮动）：标准版 699 元赠 3 个月会员（会员期内无限转写），礼盒版 999 元含一年会员；非会员每月 600 分钟转写额度。评测指出的短板不多：需搭配磁吸卡套（无磁吸手机要另配磁吸环），核心 AI 功能依赖会员。

这个赛道 2026 年已经打成一锅粥（时代财经口径）：出门问问 TicNote 999 元起（续航 20 小时）、Plaud Note Pro 1299 元（30 小时，长续航版 50 小时）、钉钉 DingTalk A1、讯飞录音卡，华强北还有 120–150 元的"平替"。得到 GetSeed 的差异化就一条：**录音直接灌进得到大脑的记忆库和内容生态**，别家卖硬件，它卖的是硬件后面的订阅。

## 六、开放生态：MCP / CLI / Skill / OpenAPI / 聊天机器人

这是我最初调研的部分，从官网开放平台页 + 前端代码逆向 + GitHub 仓库核实过的一手信息。得到大脑把同一套笔记能力（增删改查、转写、知识库、标签、语义召回 recall、博主/直播订阅、图片上传 OSS 直传）包装成了五种接入方式：

### 6.1 MCP Server

`npx -y @getnote/mcp`（Node ≥20），[getnote-mcp](https://github.com/iswalle/getnote-mcp)（TypeScript，90 stars）共 **38 个工具**：笔记读取（列表/详情/原文/转写/时间线/待办）、写入（save_note 三种类型 + 异步任务进度）、语义召回（全局/知识库内）、知识库与文件夹管理、图片上传三步曲、博主订阅、直播订阅、配额查询等。凭证用开放平台的 API Key + Client ID。

### 6.2 CLI 与 Skill

[getnote-cli](https://github.com/iswalle/getnote-cli)（Go，176 stars）`npm install -g @getnote/cli`，`getnote auth login` 走浏览器 OAuth（或直接给 API Key），token 存 `~/.getnote/config.json`，支持 `-o json` 给脚本和 Agent 用。开放平台页还提供"一句话安装"：把 `npm install -g @getnote/cli@latest && getnote setup` 丢给 WorkBuddy/Codex/Claude/小龙虾（OpenClaw）/Cursor/Gemini CLI/Windsurf/OpenCode/Cline 等 AI 工具，让它自动装好配置好——这是很聪明的分发方式。另有 [getnote-openclaw](https://github.com/iswalle/getnote-openclaw)（OpenClaw Skill，132 stars）和 [getnote-dsh-plugin](https://github.com/iswalle/getnote-dsh-plugin)（DeepSeek Harness 插件）。GitHub org（iswalle）共 6 个仓库，全部只覆盖 Agent 侧。

### 6.3 OpenAPI 与企业接入

`https://openapi.biji.com/open/api/v1`，请求头 `Authorization: gk_live_xxx`（无 Bearer 前缀）+ `X-Client-ID: cli_xxx`。个人开发直接用 API Key；企业走 **OAuth 设备授权流**：申请授权码 → 员工打开 verification_url 确认（或扫码）→ 换 Grant ID（grt_）→ 带 `X-Grant-ID` 头代员工调用。测试应用 grant 上限 5 个、7 天过期；生产应用需企业认证（目前仅开放给 GetSeed 录音卡采购企业），grant 上限 1000、有效期 1 年。还有 Webhook（录音卡笔记事件推送）和扣子（Coze）插件。

### 6.4 聊天工具机器人（四个平台四种打法）

「我的授权」页四个平台已上线，接入后"在 IM 里保存文字、链接和图片，并搜索、追问已有笔记"。机制各不相同（前端代码逆向核实）：

- **飞书**：网页点「创建飞书智能体」→ 跳飞书授权页 → 得到后台代建飞书企业应用并设为全员可用（有完整的安装状态机：需更新/需设置/接入中/已接入）；
- **企业微信**：网页出二维码，企业管理员手机确认后"一键创建得到大脑智能机器人并自动完成接入"（服务端自动建长连接）；
- **钉钉**：用户自己去钉钉开发者后台建企业内部应用（加机器人能力、消息接收选 **Stream 模式**），把 Client ID/Secret 填回网页——官方教程原话"得到大脑只使用 Stream 长连接，不需要配置公网地址、AES Key、Token 或 Webhook"；
- **微信（个人号）**：「小步微信助手」，会员专属 + 灰度。网页生成二维码 → 微信扫码 → 手机上显示六位安全码回填网页 → 绑定完成，之后在微信里像跟好友聊天一样记笔记。个人微信没有官方机器人 API，这是四个平台里唯一"曲线救国"的。

四个平台共用一套绑定层：机器人发绑定卡片（带一次性 code）→ 手机打开 `/openapi/channel/bind` 落地页 → 登录确认 → IM 身份与得到账号关联。整体哲学一句话：**一切收发都在得到服务端的长连接里完成，IM 平台只是皮**。

一个值得记录的细节：官方文档自述"付费模式尚未最终确定"，文档里写的知识库额度（免费 3 个）与官网价格页（免费 10 个）已经对不上——免费额度还在调整期，引用数字时以官网实时口径为准。

选型建议（个人观点）：免费档足够试出"语音转笔记 + AI 总结"的价值；重度记录者（每天会议/上课/播客）值得上 299 会员，主要买无限转写和无限 AI 能力；专家版只适合以写作为生且认得到方法论的人。

## 八、第三方视角与我的观察

**评价的两极**。正面：知乎实测作者认为它是"目前整体用下来最低门槛、最简单也最实用的 AI 笔记软件"，"光是作为笔记软件就已经非常好上手"；用户反馈区（官网展示）大量是"每周周会都打开一次，AI 自动整理纪要""近期最喜欢的笔记类应用"。负面：专家版定价争议（买完第二天退款的案例）、"小步背后的模型不算特别强大"（这句其实来自一个总体正面的评测，说明大家默认它的壁垒不在模型）。

**我的观察**：得到大脑是教科书级的"生态飞轮"打法——

1. **入口做宽**：App/桌面端/插件/小程序/硬件/IM 机器人/MCP/CLI，能灌数据的地方全给你；
2. **记忆做深**：所有入口汇入同一个记忆库，用得越久迁移成本越高（"小步眼中的你"甚至能导出成给其他 AI 的个人档案，看似开放，实则是把画像主权留在得到）；
3. **能力分层收费**：记录免费、AI 加工按次、无限量包月、专家工作流高价；
4. **内容库护城河**：转写总结谁都能做，但"回答限定得到课程/电子书 + 附引用"只有得到能做，这是它区别于通义听悟、讯飞听见、飞书妙记的关键。

风险同样明显：AI 录音卡硬件赛道 2026 年已是红海（华强北平替 120 元起）；笔记记忆的竞品（ima、Memobird 类、各家"AI 备忘录"）在免费送相似能力；专家版 2999 的年费在"AI 写作能力模型侧免费狂飙"的大背景下越来越难撑。它的答案显然是绑定企业采购（录音卡企业认证才开放生产级 API）和得到 App 的存量用户——这条路能不能走通，看 2027 年的续费率就知道了。
